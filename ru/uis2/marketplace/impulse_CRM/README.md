### Интеграция с impulseCRM через WebSocket  <br />



**Ценность**  <br />



Интеграция impulseCRM с виртуальной АТС UIS позволяет объединить звонки и работу с клиентами в одном окне: звонить из CRM, видеть карточку клиента при входящем вызове, хранить историю и записи разговоров, автоматически создавать лиды из новых звонков. Это повышает конверсию, ускоряет обработку обращений и делает процессы прозрачными для всей команды. <br />



**Функционал интеграции:**  <br />



- звонок по клику из карточки клиента;

- всплывающая карточка клиента при входящем звонке;

- автоматическое создание лидов в CRM;

- просмотр журнала звонков;

- прослушивание звонков в CRM. <br />

## Настройка интеграции  <br />



<details>

 <summary style="font-weight:bold;"> Шаги по подключению </summary> <br />



Чтобы UIS и impulseCRM обменивались данными, нужно создать авторизационный ключ API в личном кабинете UIS, а также добавить IP (как узнать IP — дальше в инструкции) в белый список. <br />



1. **Создайте ключ API в личном кабинете UIS**  <br />





2. **Добавьте виджет UIS в impulseCRM**  <br />



- Скопируйте ключ API, который ранее сгенерировали в личном кабинете UIS.

- Откройте личный кабинет impulseCRM, перейдите в настройки и добавьте виджет UIS. <br />




<br />



3. **Настройте виджет UIS**  <br />



- Откройте настройки виджета.

- Введите скопированный API-ключ из личного кабинета UIS в поле **«API-ключ»**. <br />




<br />



4. **Добавьте IP в белый список**  <br />



- В настройках интеграции impulseCRM нажмите кнопку **«IP адрес»** и скопируйте полученный адрес. <br />




<br />



- Этот IP необходимо добавить в белый список в личном кабинете UIS.



5. **Укажите адрес WebSocket**  <br />



- Откройте личный кабинет UIS, в левом меню выберите **«Интеграции»** → **«Все интеграции»** → найдите в поиске **«impulseCRM»** и кликните на иконку, чтобы подключить интеграцию. <br />




<br />



- В поле **«Token»** вставьте свой API-ключ UIS, с которым работали ранее.

- **«Websocket URL»** скопируйте и вставьте в настройки impulseCRM. <br />




<br />



6. **Проставьте SIP-номер для каждого пользователя impulseCRM**  <br />



- В личном кабинете UIS перейдите в **«Настройки»** → **«Сотрудники и отделы»** → выберите конкретного сотрудника, нажав на его имя. <br />




<br />



- Пролистайте настройки сотрудника вниз до пункта **«Виртуальная АТС»**. Активировав его, появятся внутренний номер и SIP-номер, который необходимо скопировать. <br />




<br />



- Вставьте этот SIP-номер в настройки пользователя в impulseCRM. <br />



<br />



7. **Настройте HTTP-уведомление в личном кабинете UIS**  <br />



- В левом меню выберите **«Интеграции»** → **«HTTP-уведомления»** → **«Добавить HTTP-уведомление»**. <br />




<br />



Заполните следующие поля: <br />



- **Название HTTP-уведомления** — любое, понятное для вас.

- **Тип события** — **«Звонки»** → **«Входящий звонок на виртуальный номер»**.

- **Условия** — никакие не добавляем.

- **Метод** — POST.

- **URL** — вставьте ссылку на Webhook из настроек интеграции.

- **Тело уведомления** — оставьте по умолчанию. <br />




<br />



8. Не забудьте **сохранить** настройки. <br />



</details>
