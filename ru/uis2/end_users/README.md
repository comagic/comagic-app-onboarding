## Конечные пользователи

<br>
<br>

<img src="end_users.svg" alt="" width="100%" height="260px"/>

<br>
<br>

Раздел позволяет добавлять конечных пользователей и управлять закрепленными за ними номерами.
**Конечный пользователь** — это человек, который использует номера организации. Для соблюдения требований законодательства необходимо указать его персональные данные. Конечным пользователем может быть сотрудник организации или исполнитель по договору ГПХ.

<br>
<br>

### Добавление конечного пользователя

<br>

1. Заполните основные данные пользователя строго в соответствии с паспортом РФ. Проверьте регистр букв, цифры, символы и пробелы. Если в паспорте нет отчества, отметьте соответствующий пункт.
2. Укажите адрес регистрации пользователя на территории РФ.
3. При необходимости отметьте «Пользователь по умолчанию», чтобы он автоматически назначался для подключаемых номеров.
4. Нажмите «Добавить». Система автоматически проверит паспортные данные пользователя. Не закрывайте страницу до завершения проверки. Если проверка выявит ошибки, исправьте данные и повторите попытку.

<br>

После успешной проверки пользователь появится в списке, и вы сможете закрепить за ним номера.

<br>
<br>

<Alert type="info">Первый добавленный пользователь автоматически становится пользователем по умолчанию. Для мобильных номеров с сим-картой и виртуальных номеров конечного пользователя необходимо назначать вручную.</Alert>

<br>
<br>

### Управление конечными пользователями

<br>

В таблице отображаются конечные пользователи, закрепленные за ними виртуальные номера и даты добавления.
Чтобы назначить пользователю номера, сделать его пользователем по умолчанию или удалить, нажмите на три точки в конце соответствующей строки.
Для изменения конечного пользователя уже подключенного номера перейдите в раздел «Управление номерами». Там можно назначить другого пользователя сразу для нескольких номеров.

<br>
<br>

<Alert type="info">Удалить пользователя с закрепленными номерами нельзя. Сначала необходимо назначить для них другого пользователя. Если пользователь установлен по умолчанию, перед удалением также назначить другого пользователя по умолчанию.</Alert>

<br>
<br>

### Подтверждение номеров на Госуслугах

<br>

Для использования мобильных номеров с сим-картой и виртуальных номеров необходимо подтвердить их закрепление за конечным пользователем на портале Госуслуг.

<br>

**Порядок подтверждения номеров:**

<br>

1. Добавьте конечного пользователя в личном кабинете UIS и закрепите за ним номера.
2. При необходимости подпишите документы на номера.
3. После передачи данных оператором связи конечный пользователь получит уведомление на Госуслугах с запросом на подтверждение номеров.
4. Пользователю необходимо проверить свои данные, сведения об организации и номера телефонов, затем отправить заявление на подтверждение.
5. После успешного подтверждения номера можно активировать.

<br>
<br>

<Alert type="info">Данные пользователя в UIS, паспорте и на Госуслугах должны совпадать. Учётная запись пользователя на Госуслугах должна быть подтверждена.</Alert>

<br>
<br>

Если требуется подтверждение номеров, над таблицей появится уведомление с указанием соответствующих пользователей.

<br>

Если в данных пользователя обнаружены ошибки, может потребоваться повторная идентификация. До их исправления и прохождения необходимых проверок использование номеров может быть ограничено.

<br>
<br>

### Пользователь М2М 

<br>

За виртуальными мобильными номерами без сим-карт можно закреплять оборудование М2М вместо конкретного человека. **Примеры устройств М2М:** терминалы для оплаты, банкоматы, онлайн-кассы, модемы, устройства ГЛОНАСС, системы безопасности и мониторинга, втоматические шлагбаумы и др.

<br>

Пользователь М2М добавляется в личный кабинет UIS автоматически. Создавать его вручную не требуется.

<br>

**Закрепление номера за пользователем М2М:**

<br>

1. Перейдите в раздел «Управление номерами».
2. При добавлении номера выберите «пользователя М2М». Для уже подключенных номеров изменить пользователя можно в настройках номера или через меню пользователя М2М в разделе «Конечные пользователи».
3. После закрепления номеров за пользователем М2М необходимо зарегистрировать их на Госуслугах через личный кабинет организации или ИП. Для этого скачайте CSV-файл с данными номеров в UIS и загрузите его при подаче заявления на Госуслугах. Позже файл можно скачать через меню пользователя М2М.

<br>
<br>

<Alert type="info">За пользователем М2М можно закрепить только виртуальные мобильные номера без сим-карт с префиксами 79, 7958 и 7999</Alert>
